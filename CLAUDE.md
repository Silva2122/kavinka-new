# КАВИНКА — карта проекта

Точка входа для любого, кто подключается к проекту. Прочитай этот файл целиком, дальше — по ссылкам.

---

## 1. Что делаем

Новый сайт **рыболовной базы «КАВИНКА»** — Магаданская область, Кавинская долина, берег реки Тауй, граница с Магаданским государственным заповедником. Основано в 2015.

Сайт информационный, не магазин: показать базу, туры, коттеджи, программу — и увести в Telegram-бот `t.me/KAVINKA_bot`. Форм обратной связи нет, это требование заказчика.

**Переписываем с нуля.** Был старый прототип (Vite + React + shadcn), из него взяли **только структуру, тексты и карточки**. Вёрстка, стиль и палитра — новые.

Сейчас собираем **примерный макет**: заказчик потом будет править тексты и подвозить новые фото. Заглушки и неточные цифры на этом этапе допустимы — главное структура и визуальный язык.

## 3. Стек и команды

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript 5 · Tailwind CSS 4.

```bash
npm run dev     # http://localhost:3000
npm run build   # прод-сборка, ей же проверяем типы
npm run lint
```

⚠️ На этой машине `npm install` падает с `EACCES` — в `~/.npm/_cacache` лежат файлы от root. Обход без sudo:

```bash
npm_config_cache=/tmp/npm-cache npm install
```

`npm audit` показывает 3 high — это транзитивные `postcss` и `sharp` внутри самого `next`. «Фикс» откатывает next до 9.3.3. Не трогать.

**Важно:** дизайн ведём в статичных HTML-файлах `design/*.html`, НЕ в `app/`. Это осознанная рабочая схема — быстро итерировать с Боссом, потом переносить в React только утверждённое. `app/globals.css` и `components/` сейчас **не отражают** актуальный дизайн, не ориентируйся на них.

**Главная страница полностью утверждена целиком** (hero → быстрые факты → о базе → виды рыб → CTA → футер, плюс хедер и анимации). Следующий шаг — **вторая страница** (следующая по `docs/STRUCTURE.md` §2, вероятно «О туре» — уточни у Босса, если неясно с чего начать). Веди её так же: сначала конкретные приёмы из `ref/`, не абстрактные словесные концепции (см. `docs/DECISIONS.md` №16 — это единственное, что реально сработало после провала первой попытки), переиспользуй уже утверждённые компоненты (кнопки, эйбрау, сетка, шкала шрифтов, приём с CSS-перфорацией, хедер, анимация) — не изобретай их заново.

Открой [docs/DESIGN.md](docs/DESIGN.md) и [docs/DECISIONS.md](docs/DECISIONS.md) целиком перед тем, как трогать дизайн — там подробно, что уже пробовали и отвергли, чтобы не наступать на те же грабли (обрезание текста на средних экранах, невидимый камуфляж, три шрифта вместо двух и т.д.).

## 6. Правила работы

- Общаться с пользователем **по-русски**, обращение — **Босс**.
- Дизайнить только когда явно попросили. Босс задаёт темп, вперёд не забегать.
- Контакты, навигацию, ссылки держать в `lib/site.ts`, не хардкодить в вёрстке.
- Контентные массивы — в `content/`, не в компонентах.
- Тексты брать из `docs/STRUCTURE.md` дословно, не сочинять свои.
- Дизайн вести в `design/*.html` (статичные файлы, не Next.js), пока Босс не утвердит — тогда переносить в `app/`/`components/`. Подробности и утверждённые решения — `docs/DESIGN.md`.
- Любые CSS/JS-макеты проверять скриншотом headless-браузера **до** показа Боссу, а не после — не гадать, как выглядит вёрстка. У headless Chrome в этом окружении минимальный размер окна 500px (нельзя честно проверить мобильные ширины <500px) и баг с пустыми скриншотами после программного скролла — при проверке контента ниже первого экрана используй якорь (`#id` в URL) или временно убирай секции перед ним, а не скролль через JS.
- `.pen` файлы читать только через Pencil MCP, не через Read/Grep.

## 7. Открытые вопросы к заказчику

Не блокеры — на макете оставляем как есть, но к сдаче надо закрыть. Полный список в [docs/STRUCTURE.md](docs/STRUCTURE.md#13-расхождения-и-открытые-вопросы), коротко:

1. Телефон `+7 914 000-00-00` — плейсхолдер.
2. Цена в hero «от 150 000 ₽» не бьётся с прайсом (240 000 ₽ за те же 7 дней).
3. Везде «7 дней», а программа тура расписана на 8.
4. Кнопки WhatsApp и MAX ведут на Telegram — нужны реальные ссылки.
5. Пакет «Рыбалка на чавычу», но чавычи нет в списке видов рыб.
6. Сезон плавает: июнь–сентябрь / июнь–октябрь / август–октябрь.
7. Логотипа нет ни в каком виде — только текст «КАВИНКА».
8. Привязка фото коттеджей к названиям сделана по порядку файлов, не подтверждена.
